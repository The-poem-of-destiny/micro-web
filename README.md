# 薄暮诗章

本项目基于酒馆助手编写模板（tavern_helper_template）创建，用于编写酒馆助手前端界面或脚本。当前包含角色卡薄暮诗章
_（命定之诗与黄昏之歌轻量版）_ 的所有内容。

`src/poem/世界书/` 内的世界书条目已按主题归类，目录树如下（括号内为该目录直属条目数）：

```
src/poem/世界书/
├── Geog/                  # 地理：国家、势力与区域
│   ├── zone/              # 冒险区域
│   ├── 奥古斯提姆帝国/
│   ├── 边陲之国/
│   ├── 伯伦斯法环/
│   ├── 潮汐王座/
│   ├── 精灵王庭/
│   ├── 诺斯加德联盟/
│   │   └── festival/      # 联盟节庆
│   ├── 萨赫拉联邦/
│   ├── 赛瑞利亚/
│   ├── 兽族联盟/
│   ├── 索伦蒂斯王国/
│   ├── 瓦伦蒂亚/
│   ├── 无尽树海/
│   ├── 翼民圣国梵尼亚/
│   └── 永夜盟约/
├── economy/               # 产业与经济
├── mechanism/             # 游戏机制与规则
├── org/                   # 组织与势力
├── power/                 # 力量体系
├── prompt/                # 生成提示词
├── race/                  # 种族
├── variables/             # 变量相关
└── world/                 # 世界观
```
